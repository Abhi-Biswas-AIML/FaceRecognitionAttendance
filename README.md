# 📸 Face Recognition Attendance System

An automated attendance tracking solution that eliminates manual entry by using computer vision and facial recognition. This system authenticates individuals via a live video stream and dynamically logs their attendance with timestamps into a database or structured file.

## 🚀 Features
* **Automated Logging:** Eliminates manual roll calls by dynamically generating timestamped attendance records.
* **High Accuracy Face Matching:** Identifies multiple registered users in a single video frame.
* **Scalable Architecture:** Designed to easily add new faces to the authorized registry without retraining the entire model.

## 🛠️ Tech Stack
* **Language:** Python
* **Computer Vision:** OpenCV
* **Facial Recognition:** `face_recognition` / dlib
* **Data Logging:** Pandas / SQL / CSV
